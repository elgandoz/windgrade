Windgrade

Nearby wind stations drawn on the terrain they sit on, each an arrow coloured by measured speed and gust. Existing tools list stations by name — which tells you nothing if you don't fly the area, because a name can't say whether a reading came from a valley floor, a summit or a gorge that funnels.

List → Nearby stations as chips, ranked by distance. Works on any phone or laptop. XCTrack overlay → Transparent arrows to stack over XCTrack's own map. Needs the setup below.

Configurator

Same URL as above. Point your phone's camera at it to open it there, then paste it into XCTrack.

Add it to XCTrack

  1. Add an XC map widget. Set its scale to the same value as Map scale above, and its rotation to North-up.
  2. Add a Web page widget over the same area, on top, and paste the URL.
  3. Turn on Allow web page to access XCTrack data — this is what gives it your position.
  4. Set refresh rate to 0, or XCTrack reloads the page every minute or two and throws away everything it has drawn.
  5. Leave Allow tapping on the web page when locked OFF, unless you want the interactive features below. With it on, the widget swallows every tap over its area — including taps meant for controls underneath.
  6. Turn on Disable unlocking so a stray swipe doesn't rearrange the page.

The two scales must match. The overlay draws its own scale bar just above XCTrack's. Same length means they match — you never have to read either number. If your phone has no such scale the overlay takes the nearest and its bar says which.

Keep the ?lat=${lat}&lng=${lng} on the end of the URL. XCTrack fills those in with its last known position, so the overlay draws straight away instead of waiting for a GPS fix. Once there is a fix, the live position takes over.

Interactive mode (optional)

Under Advanced settings → Tapping and zoom. Leave these off for normal use. They all need Allow tapping on the web page when locked turned ON — and with that on, your own zoom buttons must be moved outside the widget rectangle or they stop working.

  1. Popup timeout — tap a marker for its last few hours, as small arrows, oldest left. Tap anywhere to dismiss.
  2. Show zoom buttons — a +/− pair for the overlay's own scale, placeable on any edge or corner.
  3. Tap the screen to change scale — the top and bottom halves become invisible zoom controls. A tap on a marker opens its popup first, so the two never fight.

Changing the overlay's scale does not change the map — nothing in XCTrack lets a web widget do that. The overlay says so at the bottom until you set the map yourself.

The colours are not a safety verdict. They are a rough aid, not an assessment of whether a flight is safe. Everything shown is measured — altitude, speed, gust, direction — with no interpolation between stations and no lee-side guesses. Readings cannot work offline. Anything marked stale is old and must be treated as unknown.
