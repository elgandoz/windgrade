Tools

Diagnostic pages. You do not need any of these to fly with Windgrade — they exist to check the overlay against XCTrack and to record what was measured.

Checking the overlay against XCTrack

Overlay registration Draws a grid over XCTrack's map so you can see whether the two line up. Use this if the arrows look shifted. CSS pixel ruler A ruler across the screen. Read XCTrack's own scale bar against it and you get its map resolution directly, with no assumption of ours in the way. This is the instrument that settled how the scale works.

The marker itself

Marker geometry Every fill and rim colour pair, at every size, so the whole scale can be judged at once. arrow.svg The master shape, editable.

What this device can do

Capability probe Storage, network, WebGL and screen density, as XCTrack's browser reports them. Run this on a phone that misbehaves. Tap pass-through Answered: taps do not pass through to XCTrack underneath. Kept so the answer can be re-checked when XCTrack changes.
