Windgrade

Nearby wind stations drawn on the terrain they sit on, each an arrow coloured by measured speed and gust. Existing tools list stations by name — which tells you nothing if you don't fly the area, because a name can't say whether a reading came from a valley floor, a summit or a gorge that funnels.

List → Nearby stations as chips, ranked by distance. Works on any phone or laptop. XCTrack overlay → Transparent arrows to stack over XCTrack's own map. Needs the setup below.

Configurator

Same URL as above. Point your phone's camera at it to open it there, then paste it into XCTrack.

Add it to XCTrack

  1. Add an XC map widget. Set its scale to the same value as Map scale above — the list is XCTrack's own — and its rotation to North-up.
  2. Add a Web page widget over the same area, on top, and paste the URL.
  3. Turn on Allow web page to access XCTrack data — this is what gives it your position.
  4. Set refresh rate to 0. Anything else makes XCTrack reload the page every minute or two and throw away everything it has drawn.
  5. Leave Allow tapping on the web page when locked OFF. The overlay has nothing to tap, and with it on the widget swallows every tap over its area — including the ones meant for your own zoom buttons underneath. Measured; see docs/findings.md.
  6. Turn on Disable unlocking so a stray swipe doesn't rearrange the page.

The two scales must match. The configurator lists XCTrack's own 23 scale steps, so pick the same words in both places. The pairing to real ground resolution was measured, not guessed: XCTrack's ladder is not on integer map zoom levels. The overlay prints its scale in the corner so a mismatch shows up as two labels disagreeing, rather than as arrows quietly sitting on the wrong ridge.

An empty overlay is normal while the GPS is still getting a fix. The list page never goes blank, because there a blank page just reads as broken.

The colours are not a safety verdict. They are a rough aid on a supplied scale, not an assessment of whether a flight is safe. Everything shown is measured — station altitude, speed, gust, direction — with no interpolation between stations and no lee-side inference, because Alpine terrain makes such guesses unreliable and a confident wrong answer is worse than none. Readings cannot work offline. Anything marked stale is old and must be treated as unknown.
