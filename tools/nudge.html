Nudged markers over terrain

The overlay moves a marker down when it would overlap one already placed, rather than dropping the reading — see draw() in widget.html. This page exists because a canvas drawn asynchronously does not survive a headless screenshot, so the widget's own markers cannot be checked that way. Here the same WG.marker calls run synchronously on load, over bands standing in for snow, rock, forest, a river and an airspace edge.

What to judge: the number and the altitude must stay fully legible on a moved marker — they are drawn at full strength on purpose, because the number is the fallback for a colour scale many pilots cannot separate. Only the arrow fades. Fading the whole marker to 0.6 was measured as marginal against dark forest.
